# AS PAY — калькулятор рассрочки

Полностью рабочий, статический (HTML/CSS/JS, без сборки и зависимостей)
онлайн-калькулятор рассрочки для AS PAY — «Рассрочка по нормам ислама».

## Запуск

Проект не требует сборки. Достаточно открыть `index.html` в браузере,
либо поднять любой статический сервер из корня папки:

```bash
# любой из вариантов
python3 -m http.server 8080
npx serve .
```

Затем открыть `http://localhost:8080`.

## Деплой

Это обычный статический сайт — файлы `index.html`, `css/`, `js/`, `assets/`.
Его можно сразу разместить на:

- GitHub Pages
- Netlify / Vercel (папка проекта как есть, build command не нужен)
- Любой хостинг, отдающий статические файлы

## Домен aspay.ru (GitHub Pages)

В корне репозитория уже лежит файл `CNAME` с доменом `aspay.ru` — это
всё, что можно настроить со стороны кода. Остальное делается один раз
в интерфейсе GitHub (доступ к настройкам репозитория нужен человеку,
не автоматизации):

1. `Settings → Pages` в репозитории → **Source**: `Deploy from a branch`
   → выбрать нужную ветку и папку `/ (root)` → **Save**.
2. Там же в поле **Custom domain** ввести `aspay.ru` и сохранить —
   GitHub подтянет уже существующий файл `CNAME`.
3. У регистратора домена `aspay.ru` добавить DNS-записи:
   - 4 × A-записи для корневого домена на IP GitHub Pages:
     `185.199.108.153`, `185.199.109.153`, `185.199.110.153`,
     `185.199.111.153`;
   - (опционально) CNAME-запись для `www.aspay.ru` →
     `asadam077.github.io`, если нужен редирект с www.
4. После распространения DNS (от нескольких минут до пары часов)
   включить галочку **Enforce HTTPS** в тех же настройках Pages —
   сертификат Let's Encrypt GitHub выпускает и продлевает
   автоматически, никаких дополнительных действий не требуется.

## Как работает калькулятор

Клиент вводит только два значения — **стоимость товара** и
**первоначальный взнос**. Дальше всё считается автоматически, без
отдельной кнопки «рассчитать»:

1. Сразу под полями появляется **таблица всех вариантов рассрочки**
   (сроки от 3 до 12 месяцев одновременно): срок, наценка, итоговая
   сумма и ежемесячный платёж (самый заметный элемент строки).
   Недоступные при текущих цифрах сроки не скрываются, а показываются
   приглушённым цветом с подписью «Недоступно» и краткой причиной.
2. Клик по доступной строке делает её активной и раскрывает блок
   «Ваш вариант» ниже — с той же детализацией и графиком платежей, что
   и раньше (сумма наценки, сумма будущих платежей, итоговая
   стоимость, копирование расчёта).
3. Блок **«По вашим параметрам»** сразу показывает, доступна ли
   рассрочка, сумму взноса, сумму в рассрочку и нужен ли поручитель.
4. Блок **«Условия рассрочки»** — краткая памятка по возрасту и
   поручителю, с необязательной проверкой «Вам уже исполнился 21 год?».

## Логика расчёта (кратко)

Реализована в `evaluateTerm()` / `getGlobalStatus()` (`js/app.js`)
строго в этом порядке — формула общая для каждого из сроков 3–12 в
таблице:

1. Базовая торговая наценка = `месяцы × 6%` (константа
   `MARKUP_PER_MONTH`). Это единственная формула, по которой
   определяется фиксированная наценка — никаких сложных процентов,
   процента на процент и начислений на остаток долга.
2. Рассрочка без первоначального взноса (0 ₽) разрешена только при
   одновременном выполнении двух условий: розничная стоимость
   ≤ 50 000 ₽ (`ZERO_DOWN_MAX_PRICE`) **и** срок от 3 до 8 месяцев
   включительно (`ZERO_DOWN_MAX_MONTHS`). Свыше 50 000 ₽ без взноса
   рассрочка не оформляется ни на какой срок — все 10 строк таблицы
   помечаются недоступными с этой причиной. Если срок 3–8 — строки
   доступны, 9–12 — недоступны с пометкой «Без взноса — доступно на
   срок до 8 мес.».
3. Если взнос больше 0, минимальный взнос — 20% от розничной стоимости
   (`STANDARD_MIN_DOWN_PERCENT`). Взнос меньше минимума — расчёт не
   выполняется ни для одного срока, показывается сообщение с точной
   суммой.
4. Взнос (в том числе 0 ₽) всегда сначала вычитается из розничной
   стоимости — наценка считается только на остаток. Единая формула
   для любого размера взноса, без деления на пороги. Клиенту при этом
   показывается не эта внутренняя база расчёта, а итоговый процент
   наценки относительно полной розничной цены (`finalMarkup / price`).
5. Точный ежемесячный платёж округляется вверх до ближайших 100 ₽ —
   и именно эта округлённая сумма умножается на количество месяцев,
   формируя сумму будущих платежей. Все платежи одинаковые: разница от
   округления учитывается как небольшая корректировка самой торговой
   наценки, а не как отдельный последний платёж. Инвариант
   `monthlyPayment * months === finalInstallmentAmount` выполняется
   всегда для любого успешного расчёта.
6. Итоговая стоимость фиксируется один раз при расчёте и не меняется
   со временем — рассрочка не пересчитывается при просрочке.

## Поручитель (новое правило)

Определяется функцией `getGuarantorStatus()` (`js/app.js`) — не
зависит от выбранного срока, только от взноса и остатка
(`остаток = стоимость товара − первоначальный взнос`):

1. Взноса нет (0 ₽) → поручитель обязателен всегда.
2. Взнос есть и остаток < 50 000 ₽ → поручитель не требуется.
3. Взнос есть и остаток ≥ 50 000 ₽ → поручитель обязателен.

## Возраст

Отображается как справочное условие «Возраст — от 21 года» в блоке
«Условия рассрочки», плюс необязательная самопроверка «Вам уже
исполнился 21 год?» — ответ «Нет» показывает мягкое уведомление, не
блокируя калькулятор.
