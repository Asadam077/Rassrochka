# AS PAY — калькулятор рассрочки

Полностью рабочий, статический (HTML/CSS/JS, без сборки и зависимостей)
онлайн-калькулятор рассрочки для AS PAY — «Рассрочка по нормам Шариата».

## Запуск

Проект не требует сборки. Достаточно открыть `index.html` в браузере,
либо поднять любой статический сервер из корня папки:

```bash
# любой из вариантов
python3 -m http.server 8080
npx serve .
```

Затем открыть `http://localhost:8080`.

## Деплой

Это обычный статический сайт — файлы `index.html`, `css/`, `js/`, `assets/`.
Его можно сразу разместить на:

- GitHub Pages
- Netlify / Vercel (папка проекта как есть, build command не нужен)
- Любой хостинг, отдающий статические файлы

## Домен aspay.ru (GitHub Pages)

В корне репозитория уже лежит файл `CNAME` с доменом `aspay.ru` — это
всё, что можно настроить со стороны кода. Остальное делается один раз
в интерфейсе GitHub (доступ к настройкам репозитория нужен человеку,
не автоматизации):

1. `Settings → Pages` в репозитории → **Source**: `Deploy from a branch`
   → выбрать нужную ветку и папку `/ (root)` → **Save**.
2. Там же в поле **Custom domain** ввести `aspay.ru` и сохранить —
   GitHub подтянет уже существующий файл `CNAME`.
3. У регистратора домена `aspay.ru` добавить DNS-записи:
   - 4 × A-записи для корневого домена на IP GitHub Pages:
     `185.199.108.153`, `185.199.109.153`, `185.199.110.153`,
     `185.199.111.153`;
   - (опционально) CNAME-запись для `www.aspay.ru` →
     `asadam077.github.io`, если нужен редирект с www.
4. После распространения DNS (от нескольких минут до пары часов)
   включить галочку **Enforce HTTPS** в тех же настройках Pages —
   сертификат Let's Encrypt GitHub выпускает и продлевает
   автоматически, никаких дополнительных действий не требуется.

## Логотип

В диалоге не был прикреплён файл логотипа, поэтому в `assets/logo.svg`
создан аккуратный placeholder-вордмарк «AS PAY» в фирменной палитре
(тёмно-синий + золотой, геометрический знак — два наложенных квадрата,
образующих 8-угольную звезду). Чтобы подставить настоящий логотип —
просто замените файл `assets/logo.svg` (и при желании `assets/favicon.svg`)
на официальный, сохранив имена файлов: они уже подключены в `index.html`.

## Логика расчёта (кратко)

Реализована в `calculate()` (`js/app.js`) строго в этом порядке:

1. Торговая наценка = `месяцы × 5%` от розничной стоимости товара;
   общая стоимость = розничная стоимость + наценка.
2. Рассрочка без первоначального взноса (0 ₽) разрешена только при
   розничной стоимости ≤ 50 000 ₽ (константа `NO_DOWN_MAX_PRICE`).
   Иначе показывается мягкое уведомление, без стандартного расчёта.
3. Если взнос больше 0, минимальный взнос — 25% от розничной стоимости
   без наценки (константа `MIN_DOWN_PERCENT`). Взнос меньше минимума —
   расчёт не выполняется, показывается сообщение с точной суммой.
4. Взнос от 25% до 40% (не включая 40%) → стандартный расчёт: остаток
   (общая стоимость − взнос) делится на выбранный срок.
5. Взнос 40% и более от розничной стоимости → блок «Индивидуальные
   условия» с CTA, который открывает WhatsApp с готовым текстом
   заявки (номер компании — константа `WHATSAPP_NUMBER`, см. ниже).
   Порог строгий: ровно 40% уже относится к индивидуальным условиям,
   а не к стандартному расчёту (`down * 100 >= price * 40`).
6. Отображаемый ежемесячный платёж округляется вверх до ближайших
   100 ₽; последний платёж корректируется так, чтобы сумма всех
   платежей точно равнялась остатку к выплате (функция `buildSchedule`).
   Для очень маленьких сумм, где такое округление невозможно без
   отрицательного платежа, используется безопасное запасное
   распределение.
7. Никаких сложных процентов, начисления на остаток долга или
   увеличения стоимости после оформления — торговая наценка
   фиксируется один раз при расчёте.

## Номер WhatsApp

Номер компании для кнопки «Получить индивидуальные условия» вынесен в
константу `WHATSAPP_NUMBER` в начале `js/app.js`:

```js
var WHATSAPP_NUMBER = '79290930303';
```

Формат — только цифры, с кодом страны, без `+`, пробелов и дефисов.
